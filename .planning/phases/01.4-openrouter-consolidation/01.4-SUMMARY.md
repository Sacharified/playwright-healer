# Phase 01.4: OpenRouter Consolidation — Summary

**Phase goal:** Replace the four-provider input surface from Phase 01.1 with a three-provider surface where one OpenRouter adapter subsumes Anthropic, Gemini, and any future cloud model behind a single OpenAI-compatible endpoint. `github` (free tier) and `ollama` (localhost) keep dedicated paths because OpenRouter cannot serve them.

**Status:** Complete. 5 decisions captured (D-01 through D-05), 3 commits, 484/484 tests passing, typecheck clean.

## What was built

### New OpenRouter adapter

- **`src/healer/adapters/openrouter.ts`** (280 LOC) — OpenAI-compatible chat completions adapter pointed at `https://openrouter.ai/api/v1`. Mirrors `github.ts` pattern: manual MCP tool-use loop (`@modelcontextprotocol/sdk` Stdio transport), SEC-04 audit invariant on the canonical `mcp__playwright__<name>` form, OpenAI-shape tool-call dispatch, FixProposal/NoFixProposable JSON parsing.
- Both `max_turns` AND `max_budget_usd` enforced as pre-call gates (versus `github.ts` which only enforces `max_turns` since the free tier has no per-token charge).
- Per-call USD comes from `usage.cost` on every response. The legacy `usage: { include: true }` opt-in is deprecated (verified against OpenRouter docs); usage is always returned.
- Optional attribution headers `HTTP-Referer` + `X-OpenRouter-Title` per OpenRouter authentication guide.
- **`src/healer/adapters/openrouter.test.ts`** (22 tests) — full coverage matching `github.test.ts`, plus three OpenRouter-specific tests: `usage.cost` cost accumulation, `maxBudgetUsd` gate trip, missing-cost fallback to 0 (no NaN).

### Schema + config

- `src/shared/config.ts`: `ProviderEnum` narrowed from 4 (`anthropic | gemini | github | ollama`) to 3 (`openrouter | github | ollama`). Default changed from `anthropic` to `openrouter`. `DEFAULT_MODELS.openrouter = 'anthropic/claude-sonnet-4.6'` (note OpenRouter's slug uses a DOT for the minor version, distinct from Anthropic SDK's hyphenated `claude-sonnet-4-6`). `DEFAULT_ENDPOINTS.openrouter = 'https://openrouter.ai/api/v1'`. `superRefine` per-provider api-key gate preserved unchanged (Ollama localhost may omit the key; openrouter and github require it).
- `src/healer/index.ts` `selectAdapter()`: switch narrows from 5 cases (the additive 5-wide enum from earlier in the same session) to 3.
- `action.yml`: `provider` description and default updated.

### Deletions (subsumed by OpenRouter)

## Decisions (5)

- **D-01:** Hard cutover. `provider: anthropic` and `provider: gemini` removed from the enum with no alias and no bespoke error message. Standard Zod enum error names the field. Pre-release software, no external consumers.
- **D-02:** Default `provider: openrouter`, default `model: anthropic/claude-sonnet-4.6` (OpenRouter slug, dot not hyphen). Preserves the existing "leave it blank, get Claude Sonnet" mental model.
- **D-03:** Self-test scenario 4 assertions rewritten for openrouter. Scenario 5 (ollama empty-key) unchanged. No new openrouter-specific scenarios added.
- **D-04:** Single atomic implementation commit (`10e2ac0`) bundles additive openrouter adapter + destructive cleanup. Planning docs commit separately (`7aee75a`).
- **D-05:** `openai-compat.ts` shared-helper extraction (deduplicating `github.ts` and `openrouter.ts`) deferred to follow-up Phase 01.5.

## Verification

**Real-API verification (2026-05-05):** Both empirical gates from the source plan passed against live OpenRouter API.
- Gate 1 — `usage.cost` field present: anthropic/claude-sonnet-4.6 returned `$0.000117`, google/gemini-2.5-pro returned `$0.000135`, both as JSON `number`.
- Gate 2 — `tool_calls` shape uniformity: identical outer keys `[function, id, index, type]`, identical `function` keys `[arguments, name]`, `function.arguments` is JSON `string` on both upstreams.
