## Area 1 — Deprecation strategy

| Option | Description | Selected |
|--------|-------------|----------|
| Hard cutover with helpful error | Zod rejects `provider: anthropic` and `provider: gemini` with a clear migration message. | |
| Transparent alias | Zod superRefine rewrites `provider: anthropic` → `provider: openrouter, model: anthropic/claude-sonnet-4.6` and emits a `core.warning` deprecation notice. | |
| Hard cutover, no special error | Just remove from the enum. Zod's default error names the field. Lowest code volume; least helpful UX. | ✓ |

**User's choice:** Hard cutover, no special error.
**Notes:** Pre-release software, no external consumers. User opted for the most aggressive option (no alias, no bespoke error message) to minimize maintenance debt. Standard Zod enum error message names the field and lists allowed values, which is sufficient migration UX given the project's pre-1.0 status.
