# Phase 03.1 Plan 02: action.yml Infrastructure (CRACK-2 + CRACK-3 + Skip Flags) Summary

**One-liner:** Added git credential insteadOf substitution (CRACK-2), version-locked Playwright browser install (CRACK-3), and three heal-mode demo skip-flag inputs + env wiring to action.yml.

## What Was Built

Four targeted edits to `action.yml` that unblock the first end-to-end heal demo:

**1. Three new inputs (skip flags)**
- `skip-deterministic-check` — lets the healer attempt fixes on always-failing tests (demo mode)
- `skip-post-fix-validation` — skips Playwright re-run validation; fixture-ci.yml on the PR is the truth source
- `skip-diff-lint` — skips forbidden-pattern lint check during Phase 03 demo; re-enables in Phase 04
- All `required: false`, `default: 'false'` — backward compatible with all existing callers

**2. CRACK-3: Playwright browser install step (Step 3.1)**
- Inserted after Step 3 (setup-node) and before Step 4 (setup-command)
- Runs `node_modules/.bin/playwright install chromium --with-deps` from `${{ github.action_path }}`
- Uses action's own node_modules binary (version 1.60.0-alpha matching @playwright/mcp@0.0.70)
- Guarded by `if: inputs.mode == 'heal'`

**3. CRACK-2: Git credential step (Step 5.1)**
- Inserted after Step 5 (start-command + wait-for-ready) and before Step 6 (tsx run)
- Sets `git config --global url."https://x-access-token:${HEALER_TOKEN}@github.com/".insteadOf "https://github.com/"`
- Provides HTTPS credential substitution for fix-applier.ts's `git push` without modifying TypeScript
- Guarded by `if: inputs.mode == 'heal'`

**4. Step 6 env block extension**
- Added `INPUT_SKIP-DETERMINISTIC-CHECK`, `INPUT_SKIP-POST-FIX-VALIDATION`, `INPUT_SKIP-DIFF-LINT` after `INPUT_STARTUP-TIMEOUT-SECONDS`
