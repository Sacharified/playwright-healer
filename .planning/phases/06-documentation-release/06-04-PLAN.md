**`docs/auto-merge.md`** — full companion doc per D-05 structure:

Sections:
1. **Why auto-merge is opt-in** — 1–2 paragraphs: healer PRs are code changes that affect test reliability; auto-merge introduces automation risk. Default-OFF means consumers must consciously enable it. The four-condition trust gate (pass rate, fix class, no forbidden patterns, no security contract violations) makes the merge decision auditable.

2. **Required repository settings** — lifted verbatim from current README.md lines 4–14 (the four numbered prerequisites). Expand them with concrete GitHub UI paths:
   - Repository Settings → General → Pull Requests → Allow auto-merge: ON
   - Repository Settings → General → Pull Requests → Allow squash merging: ON (action passes `mergeMethod: SQUASH`)
   - Branch protection rule on default branch: require at least one status check (Settings → Branches → Branch protection rules)
   - healer_token PAT scope: `repo` (classic PAT) or `Contents: write` + `Pull requests: write` (fine-grained PAT)

3. **The reasoning band format** — the four trust-gate conditions and their outcome:
   - Post-fix validation pass rate ≥ threshold (configurable via auto_merge_pass_rate)
   - Fix class within allowed set (configurable via auto_merge_fix_classes)
   - No forbidden patterns in diff (diff-lint gate: no waitForTimeout, no positional selectors, no weakened assertions)
   - No security-contract violations (tool-naming audit)
   - Outcome row: all four pass → auto-merge set; any fail → PR stays open for human review

4. **Soft-fail behavior matrix** — table mapping GitHub API errors to core.warning text:
   | GitHub error | core.warning text | Consumer action |
   |---|---|---|
   | allow_auto_merge not enabled | "Auto-merge is disabled in repository settings. Enable it via Settings → General → Pull Requests." | Enable repo setting |
   | No required status checks | "Branch protection requires at least one status check. Configure via Settings → Branches." | Add branch protection |
   | Token insufficient scope | "healer_token lacks permission for auto-merge. Add Contents:write + Pull requests:write." | Update PAT |
   | GraphQL mutation error | "Unexpected GitHub API error: <message>. PR requires manual merge." | Manual merge |

5. **T-05-06 SKIP_SENTINEL preservation** — 1 paragraph: auto-merge PRs from playwright-healer include `[skip-healer]` in the commit message (T-05-06). This prevents the loop where a merged heal PR triggers another heal cycle. The sentinel is verified by the `shouldSkipIngest()` check in `src/shared/loop-guard.ts`.

6. **Live demo evidence** — 1 line: "See `tests/fixture-app/uat-evidence-live-auto-merge.md` for the live demo evidence once captured (D-03)." (File doesn't exist yet — this is the forward reference from CONTEXT.md D-03.)
