```bash
# 1. Ensure main is clean and at the right SHA
git checkout main

git status
# Expected: nothing to commit, working tree clean

# 2. Verify CHANGELOG has [0.1.0] section (must be true from Task 1)
grep "\[0.1.0\]" CHANGELOG.md

# 3. Create immutable v0.1.0 annotated tag
git tag -a v0.1.0 -m "playwright-healer v0.1.0

First public release. Two-workflow ingest + dispatch + heal pipeline.
Multi-provider: Anthropic, Gemini, GitHub Models, Ollama.
Auto-merge gate (Phase 5). See CHANGELOG.md for full notes."

# 4. Create moving v1 alias
git tag -f v1 v0.1.0

# 5. Push both tags
git push origin v0.1.0
git push origin v1 --force

# 6. Verify tags exist on remote
gh release list 2>/dev/null | head -5
git ls-remote --tags origin | grep -E "v0\.1\.0|refs/tags/v1$"
```

Then create the GitHub Release:
```bash
# Extract just the [0.1.0] section from CHANGELOG.md for the release notes
# (The full CHANGELOG includes the [Unreleased] header which we don't want in the release body)
awk '/^## \[0\.1\.0\]/{found=1} found{print} /^## \[Unreleased\]/{if(found) exit}' CHANGELOG.md \
  | grep -v "^## \[Unreleased\]" > /tmp/release-notes.md

gh release create v0.1.0 \
  --title "playwright-healer v0.1.0" \
  --notes-file /tmp/release-notes.md \
  --draft

# Review the draft release, then publish:
gh release edit v0.1.0 --draft=false
```

After publishing, verify:
```bash
# Confirm release is live
gh release view v0.1.0 --json url,tagName,isDraft --jq '.'

# Confirm v1 alias points to v0.1.0 SHA
git ls-remote --tags origin | grep "refs/tags/v1$"
V0_SHA=$(git rev-list -n 1 v0.1.0)
V1_SHA=$(git ls-remote origin refs/tags/v1 | cut -f1)
test "$V0_SHA" = "$V1_SHA" && echo "v1 alias points to v0.1.0 SHA" || echo "MISMATCH"
```

Also update the cross-repo `Sacharified/playwright-healer-test:.github/workflows/sc1-healer.yml` to use `@v1` now that the tag exists:
```bash

  -F message="chore(06-06): update to published v1 tag" \
  -F "content=$(base64 < /tmp/sc1-healer-v1.yml)" \
  -F sha="$SC1_SHA"
```
